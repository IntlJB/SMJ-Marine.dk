Metalopgaver løst professionelt på havnen

Reparation og fabricering direkte på havnen gør mange metalopgaver enklere for bådejeren. Vi vurderer adgang, materiale og sikkerhed på stedet, så både små reparationer og specialfremstilling kan løses med den rigtige metode.

01

Mobil svejser havn

Mange svejseopgaver er upraktiske at flytte væk fra båden. Som mobil svejser havn kan vi vurdere og ofte løse opgaven direkte på båden eller på havnen, hvis adgang, strøm, vejr og sikkerhed tillader det.

  • Svejsning direkte på båden
  • Mobil svejser havn
  • Store og små opgaver
  • Besigtigelse på stedet
02

Rustfrit stål og TIG svejsning

Rustfrit stål båd bruges til reling, beslag, søgelænder, badeplatforme og fittings. TIG svejsning rustfrit stål båd er relevant, når samlingen skal være præcis, stærk og pæn.

  • Rustfrit stål båd
  • TIG svejsning rustfrit stål båd
  • Reparation af knækket beslag båd
  • Specialfremstilling
03

Søgelænder, beslag og badeplatform

Vi hjælper med reparation af søgelænder, nyt søgelænder båd, utæt søgelænder reparation, montering af badeplatform og badeplatform rustfrit stål. Belastning, pasform og fastgørelse vurderes altid først.

  • Reparation af søgelænder
  • Nyt søgelænder båd
  • Montering af badeplatform
  • Badeplatform rustfrit stål
04

Aluminium og forstærkning

Aluminiumssvejsning båd og forstærkning af agterspejl vurderes konkret, fordi materiale, godstykkelse og belastning betyder meget. Vi siger hellere tydeligt fra end at lave en løsning, der ikke holder.

  • Aluminiumssvejsning båd
  • Forstærkning af agterspejl
  • Materialevurdering
  • Holdbar løsning
Pris og gennemsigtighed

Hvad koster svejsning på båd?

Prisen afhænger af materiale, adgang, sikkerhed, demontering, forarbejde og om der er tale om reparation eller specialfremstilling. En reparation af knækket beslag båd er ikke samme opgave som nyt søgelænder eller montering af badeplatform. Vi vurderer først og aftaler omfanget tydeligt.

Materiale

Rustfrit stål og aluminium kræver forskellige metoder og forberedelse.

Adgang på havnen

Direkte arbejde på båden afhænger af plads, strøm, læ og sikkerhed.

Reparation eller nyt

Reparation, montering og specialfremstilling prissættes forskelligt.

Belastning og sikkerhed

Dele som søgelænder, badeplatform og agterspejl kræver korrekt vurdering.

Trygheds-FAQ

Ofte stillede spørgsmål

Kan I svejse direkte på båden?

Ja, i mange tilfælde kan vi udføre svejsning direkte på båden eller på havnen. Det afhænger af materiale, adgang, sikkerhed, strømforhold og opgavens type.

Kører I ud til alle havne?

Vi tilbyder mobil svejser havn på Sjælland efter aftale. Muligheden afhænger af opgave, afstand, adgangsforhold og planlægning.

Kan I arbejde med rustfrit stål og aluminium?

Ja. Vi kan hjælpe med rustfrit stål båd og aluminiumssvejsning båd efter konkret vurdering.

Hvad hvis vejret er dårligt?

Svejsning og metalopgaver kræver sikre arbejdsforhold. Regn, vind, fugt eller manglende læ kan betyde, at opgaven flyttes.

Kan I lave søgelænder eller badeplatform?

Ja, vi kan hjælpe med nyt søgelænder båd, reparation af søgelænder, montering af badeplatform og badeplatform rustfrit stål efter vurdering.

Kan I lave specialfremstilling?

Ja. Vi kan hjælpe med specialfremstilling af beslag, forstærkninger og praktiske metaldele, når standardløsninger ikke passer.
